# Виджет

## Описание:

Делаем фичу для личного кабинета клиента банка.
Это виджет, который показывает несколько последних успешных банковских операций клиента.

## Установка:

1. Клонируйте репозиторий:
```
git clone
```

2. Установите зависимости:
```
pip install -r requirements.txt
```

3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```

# Обработка транзакционных данных
## Описание
Этот проект предоставляет функциональность
для чтения и обработки файлов с транзакционными данными в форматах CSV и XLSX

## Функциональность
1. Чтение CSV-файлов с транзакциями.
2. Чтение XLSX-файлов с транзакциями.
3. Вывод первых строк данных для предварительного просмотра

## Использование
1. Поместите файлы transactions.csv и transactions_excel.xlsx в корневую директорию проекта.

## Установка зависимостей
1. poetry add pandas
2. poetry add pandas-stubs

## Новая функциональность

1. **Загрузка данных**:
   - Возможность загружать транзакции из файлов в форматах JSON, CSV и XLSX.
   - Функции:
     - `load_transactions_from_json(file_path)` — Загружает транзакции из JSON-файла.
     - `load_transactions_from_csv(file_path)` — Загружает транзакции из CSV-файла.
     - `load_transactions_from_xlsx(file_path)` — Загружает транзакции из XLSX-файла.
2. **Фильтрация транзакций**:
   - Фильтрация по статусу транзакции (например, "EXECUTED", "CANCELED", "PENDING").
   - Фильтрация по валюте (по умолчанию фильтруются только рублевые транзакции).
   - Фильтрация по ключевому слову в описании транзакции.

3. **Сортировка транзакций**:
   - Возможность сортировать транзакции по дате в порядке возрастания или убывания.

4. **Интерфейс пользователя**:
   - Простой текстовый интерфейс для выбора файлов, фильтрации и сортировки транзакций.
